## 컨셉 — "Control Plane"

포트폴리오를 크래프트 자랑이 아니라 **관제 화면**처럼 만들었다.
니어블랙 배경에 프로젝트를 늘어놓고, 각각이 무엇을 하고 지금 어떤 상태인지 기술 문서처럼 담백하게 쓴다.

### 화면 구성

| 섹션 | 내용 |
|---|---|
| Hero | 선언 2줄 + 에이전트 오케스트레이션 구조를 그린 배경 다이어그램 |
| Work | 프로젝트 4개 — 카드 좌우 교대, 스택·상태·저장소 링크 |
| How | 일하는 방식 9가지(규칙·위임·검증·기록·문서·관제·원격·정기 실행·복구) |
| About | 포지셔닝 + 스택 정의 리스트 |

## 디자인 원칙

이 사이트는 **"AI가 뽑은 티"가 나는 평균값 디자인을 피하는 것**을 1순위 제약으로 두고 만들었다.

- **악센트는 단 하나** — 라임(`#D6F24A`). 형광펜 마킹 · 주 CTA · 포커스 링을 전부 이 색 하나가 맡고,
  나머지 위계는 무채색(텍스트 3단 · 보더 2단)으로 만든다. 두 번째 색을 만들지 않는다.
- **서명 요소도 하나** — 형광펜 마킹. 사이트 전체에서 2번만 쓴다.
  라임 배경 + 니어블랙 텍스트라 다크·라이트 구간 양쪽에서 같은 대비(15.8:1)로 작동한다.
- **그라데이션 0곳 · 파티클 0개** — 배경 장식 대신 실제 시스템 구조를 그린 선화(線畵) 하나.
- **다크 베이스 + 라이트 인터럽트** — 다크가 세 섹션 이어진 뒤 한 번 밝게 끊어 단조로움을 깬다.
  같은 컴포넌트가 두 테마에서 그대로 동작하도록 **시맨틱 토큰을 재할당**하는 방식(3층 토큰).
- **없는 것을 있다고 쓰지 않는다** — 데모·영상이 없으면 버튼도 만들지 않고, 프로젝트 미디어도
  스크린샷인 척하지 않는 도식으로 둔다(수치·티커 없음).

### 한글 웹 타이포그래피 — 실측으로 얻은 것

| 문제 | 해결 |
|---|---|
| 헤드라인이 어절 중간에서 쪼개짐 (`치게 만/드는`) | `word-break: keep-all` |
| `max-width`에 `ch`를 쓰면 한글에서 절반만 세어 과도하게 좁아짐 | 폭 기준을 `em`으로 (한글 1자 ≈ 1em) |
| mono 폰트에 한글 글리프가 없어 시스템 고정폭으로 떨어짐 (`주 력`) | 폰트 체인에 한글 폴백을 명시 |
| 라틴 대문자용 넓은 자간(0.1em)이 한글에도 걸려 흩어져 보임 | 순수 라틴 라벨만 넓게, 한글 섞이는 값은 0~0.02em |

## 기술 선택

- **Next.js 16 (App Router)** — 정적 프리렌더. 서버·DB·환경변수가 **하나도 없다**.
- **Tailwind v4 `@theme`** — 원시 → 시맨틱 → 컴포넌트 3층 토큰. 컴포넌트는 시맨틱 토큰만 참조한다.
- **GSAP + Lenis** — 히어로 라인 리빌과 스무스 스크롤. rAF 루프는 `gsap.ticker` 하나로 통일.
- **모션은 4종만** — 히어로 리빌 · 형광펜 그어짐 · 다이어그램 흐름 · 스크롤 리빌.
  전부 `prefers-reduced-motion`에서 정지하고, 정보는 정적 최종 상태로 손실 없이 전달된다.

### 스크롤 리빌을 이벤트로 만들지 않은 이유

이벤트 기반 두 방식이 모두 **요소를 영구히 숨긴 채 남기는** 실패를 냈다.

- `ScrollTrigger`의 `start: "top 85%"` → 페이지 최하단 요소는 더 스크롤할 여지가 없어 그 선에 영영 못 닿는다.
- `IntersectionObserver` → 앵커 점프나 빠른 플릭으로 한 프레임에 지나가면 콜백 자체가 오지 않는다.

애니메이션이 안 도는 것보다 **콘텐츠가 안 보이는 게 훨씬 나쁘다.**
그래서 rAF 스로틀 스크롤 핸들러가 남은 요소의 `getBoundingClientRect()`를 직접 재는 방식으로 바꿨다.
어떤 경로로 도달했든 화면에 들어온 순간 반드시 켜지고, 대상이 20개 남짓이라 측정 비용도 없다.

## 접근성

- 대비 AA 이상 — 본문 17.9:1 · muted 5.1:1 · 라임 마킹 15.8:1
- 상태는 **색 단독으로 전달하지 않는다** — 색 + 점(●) + 텍스트 라벨
- 포커스 링 상시 표시, 본문 바로가기(skip link), 앵커 오프셋(`scroll-margin-top`)
- 모바일 메뉴는 네이티브 `<dialog>` — 포커스 트랩 · `Esc` · 포커스 복귀를 브라우저가 처리
- `prefers-reduced-motion` 전면 존중
